# Runic Wards in the Vines

## Problem
The vines of the Upside Down still form a tree with lowercase English letters written on the tunnels.

Hopper has found a way to weaken monsters before they reach the gate: place **runic wards** at junctions.  
A ward is tuned to exactly one monster word. Whenever a monster travels through an occurrence of its word that passes through a matching ward, that occurrence is disrupted and gives no power.

You must decide where to place at most `B` wards.

### Tree string
For any ordered pair of distinct vertices `(u, v)`, let the unique simple path from `u` to `v` be

`u = p0, p1, ..., pt = v`

and let the letters on its edges in that order be

`c1 c2 ... ct`.

Define `f(u, v) = c1 c2 ... ct`.

### Monster groups
There are `q` monster groups. Group `j` is described by `(u_j, v_j, k_j, w_j)`:

- it moves from vertex `u_j` to vertex `v_j`,
- its word is `s[k_j]`,
- each **undisrupted occurrence** of `s[k_j]` inside `f(u_j, v_j)` contributes `w_j` threat.

Occurrences may overlap.

### Wards
A ward is a pair `(x, k)`:

- `x` is a vertex,
- `k` is a word index.

A ward `(x, k)` disrupts an occurrence of `s[k]` on a path if and only if vertex `x` belongs to the vertex span of that occurrence.

More formally, if an occurrence of a length-`L` word starts at position `p` in `f(u, v)`, then it uses edges `p, p+1, ..., p+L-1` of the path and spans the vertices

`p_{p-1}, p_p, ..., p_{p+L-1}`.

That occurrence is disrupted if at least one chosen ward `(x, k)` has:
- the same word index `k`, and
- `x` equal to one of those spanned vertices.

An occurrence disrupted by one or more wards counts as disrupted only once.

Your task is to output any set of at most `B` distinct wards.

## Input
The first line contains four integers:

`n m q B`

- `2 ≤ n ≤ 100000` — number of vertices,
- `1 ≤ m ≤ 100000` — number of words,
- `1 ≤ q ≤ 100000` — number of monster groups,
- `0 ≤ B ≤ 2000` — ward budget.

The next `n - 1` lines describe the tree.  
Each line contains:

`a b c`

meaning there is an undirected edge between vertices `a` and `b` labeled by lowercase letter `c`.

The next `m` lines contain the words:

`s1`
`s2`
`...`
`sm`

Each word consists of lowercase English letters.

The next `q` lines describe the monster groups.  
Each line contains:

`u v k w`

- `1 ≤ u, v ≤ n`, `u ≠ v`,
- `1 ≤ k ≤ m`,
- `1 ≤ w ≤ 10^9`.

It is guaranteed that:
- the graph is a tree,
- `1 ≤ |s_i|`,
- `|s_1| + |s_2| + ... + |s_m| ≤ 100000`.

## Output
Output a feasible ward placement:

- First line: one integer `r` — the number of wards you place.
- Then `r` lines, each containing two integers `x k`, meaning a ward tuned to word `k` is placed at vertex `x`.

### Feasibility requirements
Your output is **feasible** if and only if:
- `0 ≤ r ≤ B`,
- `1 ≤ x ≤ n`,
- `1 ≤ k ≤ m`,
- all `r` pairs `(x, k)` are distinct.

If the output is infeasible, the score for that test is `0`.

## Objective
For each monster group `j`, let:

- `occ_j` = number of occurrences of `s[k_j]` in `f(u_j, v_j)`,
- `blocked_j` = number of those occurrences disrupted by at least one chosen ward.

The remaining threat of group `j` is:

`(occ_j - blocked_j) * w_j`.

The total remaining threat is:

`R = sum over all groups of (occ_j - blocked_j) * w_j`.

Your goal is to **minimize `R`**.

Equivalently, you are trying to disrupt as much weighted occurrence threat as possible.

## Scoring
For each test file, define the baseline value:

`R0 = sum over all groups of occ_j * w_j`

which is the total threat when placing no wards.

Your score for that test is:

- `0`, if your output is infeasible;
- otherwise  
  `floor(1_000_000 * (R0 - R) / max(1, R0))`.

So:
- placing no wards scores `0`,
- eliminating all threat scores `1,000,000`,
- partial improvements receive proportionally intermediate scores.

The final score is the sum of scores over all official test files.

## Constraints
- Time limit: 3 seconds
- Memory limit: 512 MB

## Example
### Sample input
```text
5 2 3 2
1 2 a
2 3 b
2 4 a
4 5 b
ab
a
1 3 1 5
1 5 1 4
3 5 2 3
```

### Sample output
```text
2
2 1
4 2
```

### Explanation
- Path `1 -> 3` has string `"ab"`. It contains one occurrence of word `1 = "ab"`, spanning vertices `{1,2,3}`. Ward `(2,1)` disrupts it.
- Path `1 -> 5` has string `"aab"`. It contains one occurrence of `"ab"`, spanning vertices `{2,4,5}`. Ward `(2,1)` disrupts it as well.
- Path `3 -> 5` has string `"bab"`. It contains one occurrence of word `2 = "a"`, spanning vertices `{2,4}`. Ward `(4,2)` disrupts it.

All occurrences are disrupted, so the remaining threat is `0`.

The baseline threat is:

`1*5 + 1*4 + 1*3 = 12`.

Thus this output gets the maximum score for this test:
`floor(1_000_000 * (12 - 0) / 12) = 1_000_000`.
