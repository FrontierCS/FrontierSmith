# Radio Marathon Lineup

## Problem

A radio station wants to air a special music marathon. You are given `n` candidate songs, and you must choose **an ordered playlist** whose total duration does not exceed a time budget `T`.

Each song `i` has:

- `t_i` — duration
- `b_i` — intrinsic appeal
- `e_i` — energy level
- `g_i` — genre id
- `a_i` — artist id

A playlist earns points from four sources:

1. **Base appeal**: longer, more appealing songs are valuable.
2. **Smooth transitions**: consecutive songs with similar energy create better flow.
3. **Genre diversity**: using more distinct genres gives a bonus.
4. **Artist repetition penalty**: repeating the same artist too often hurts the lineup.

Your task is to output any feasible playlist that maximizes the total objective.

This is an optimization problem: better playlists receive higher scores.

## Input

The first line contains five integers:

`n T S G R`

- `n` — number of songs
- `T` — total duration budget
- `S` — transition smoothness parameter
- `G` — bonus per distinct genre used
- `R` — penalty coefficient for repeated artists

The next `n` lines each contain five integers:

`t_i b_i e_i g_i a_i`

for song `i` (`1 <= i <= n`).

## Output

On the first line, print a single integer `m` — the number of songs in your playlist.

On the second line, print `m` distinct 1-based song indices in the order they will be played.

If `m = 0`, the second line may be empty or omitted.

A submission is **feasible** if:

- `0 <= m <= n`
- all printed indices are distinct integers in `[1, n]`
- the total duration of the chosen songs is at most `T`

If the output is infeasible, its objective value is defined to be `0`.

## Objective

Let your playlist be `P = [p_1, p_2, ..., p_m]`.

Define:

- **Base appeal**
  
  `Base(P) = sum(t_{p_j} * b_{p_j})` for `j = 1..m`

- **Transition bonus**
  
  For each consecutive pair `(p_j, p_{j+1})`, define
  
  `trans(p_j, p_{j+1}) = min(t_{p_j}, t_{p_{j+1}}) * max(0, S - |e_{p_j} - e_{p_{j+1}}|)`
  
  Then
  
  `Smooth(P) = sum(trans(p_j, p_{j+1}))` for `j = 1..m-1`

- **Genre diversity bonus**
  
  Let `D(P)` be the number of distinct genre ids among the chosen songs.
  
  `GenreBonus(P) = G * D(P)`

- **Artist repetition penalty**
  
  For each artist id `x`, let `cnt_x(P)` be how many chosen songs are by artist `x`.
  
  `ArtistPenalty(P) = R * sum( cnt_x(P) * (cnt_x(P) - 1) / 2 )`
  
  where the sum is over all artists appearing in the playlist.

The total objective is

`Objective(P) = Base(P) + Smooth(P) + GenreBonus(P) - ArtistPenalty(P)`

The judge computes this value exactly using 64-bit signed integers.

## Scoring

For each test file:

1. The judge computes your objective value `U`.
2. The judge also computes a **baseline** playlist and its objective value `B` using the following deterministic algorithm:

   - Sort all songs by:
     1. decreasing `b_i`
     2. increasing `t_i`
     3. increasing index
   - Scan songs in that order, and greedily keep a song if adding it does not exceed total duration `T`.
   - After the set is chosen, sort the chosen songs by:
     1. increasing `e_i`
     2. decreasing `b_i`
     3. increasing index
   - This ordered list is the baseline playlist.

3. The test score is

   `score = floor(1_000_000 * clamp(U / B, 0, 2))`

   where `clamp(x, 0, 2) = max(0, min(2, x))`.

So:

- matching the baseline gives `1,000,000`
- doing better than the baseline gives more than `1,000,000`
- scores are capped at `2,000,000` per test

The final score is the floor of the arithmetic mean of the per-test scores.

## Constraints

- `1 <= n <= 200000`
- `1 <= T <= 10^12`
- `1 <= S, G, R <= 10^6`
- `1 <= t_i, b_i, e_i <= 10^6`
- `1 <= g_i, a_i <= 10^6`
- At least one song satisfies `t_i <= T`

- Time limit: 3 seconds
- Memory limit: 512 MB

## Example

### Input
```text
6 15 6 12 10
4 8 3 1 1
5 7 5 2 2
3 9 6 1 3
2 6 2 3 1
6 10 11 2 4
4 5 7 4 5
```

### Output
```text
4
4 1 2 6
```

### Explanation

The chosen playlist is songs `[4, 1, 2, 6]`.

- Total duration: `2 + 4 + 5 + 4 = 15` (feasible)
- Base appeal: `2*6 + 4*8 + 5*7 + 4*5 = 99`
- Transition bonus:
  - `4 -> 1`: `min(2,4) * (6 - |2-3|) = 2 * 5 = 10`
  - `1 -> 2`: `min(4,5) * (6 - |3-5|) = 4 * 4 = 16`
  - `2 -> 6`: `min(5,4) * (6 - |5-7|) = 4 * 4 = 16`
  - total = `42`
- Distinct genres used: `{3,1,2,4}` so bonus = `4 * 12 = 48`
- Artist `1` appears twice, so repetition penalty = `10 * 1 = 10`

Total objective:

`99 + 42 + 48 - 10 = 179`

A higher-objective playlist would receive a higher score.
