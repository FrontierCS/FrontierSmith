# Calibration Link Design

## Problem

A laboratory has `n` unstable reactors. Reactor `i` contains `a_i` charge units that must be neutralized.

A **neutralization link** between two different reactors `i` and `j` can be used any positive integer number of times.  
Each use of the link removes exactly:

- `1` charge unit from reactor `i`, and
- `1` charge unit from reactor `j`.

So if link `(i, j)` is used `k` times, then `k` units are removed from each endpoint.

Using a link has two kinds of cost:

1. **One-time calibration cost** (paid once if the link is used at least once):
   `b_i + b_j + G * [t_i != t_j]`
2. **Per-use energy cost**:
   `|x_i - x_j| + |y_i - y_j|`

Here:
- `(x_i, y_i)` is the position of reactor `i`,
- `b_i` is its calibration parameter,
- `t_i` is its technology type,
- `G` is a global incompatibility penalty,
- `[condition]` is `1` if the condition is true and `0` otherwise.

Your task is to design a set of links and usage counts so that **all reactors end at exactly zero charge**, while minimizing the total cost.

Official test data always satisfies:
- `sum a_i` is even, and
- `max(a_i) <= sum(a_i) / 2`

so at least one feasible solution always exists.

---

## Input

The first line contains two integers:

- `n` — number of reactors
- `G` — incompatibility penalty

The next `n` lines each contain five integers describing one reactor:

- `a_i` — initial charge
- `x_i`, `y_i` — coordinates
- `b_i` — calibration parameter
- `t_i` — technology type

### Constraints

- `2 <= n <= 100000`
- `0 <= G <= 10^6`
- `1 <= a_i <= 10^6`
- `0 <= x_i, y_i <= 10^6`
- `0 <= b_i <= 10^6`
- `1 <= t_i <= 20`
- `sum a_i <= 10^9`

---

## Output

On the first line, print an integer `m` — the number of distinct links you use.

Then print `m` lines. Each line must contain:

- `i j k`

meaning that link `(i, j)` is used exactly `k` times.

### Feasibility requirements

Your output is **feasible** if all of the following hold:

- `1 <= i < j <= n`
- `k` is a positive integer
- no unordered pair `(i, j)` appears more than once
- for every reactor `v`, the sum of `k` over all printed links incident to `v` is exactly `a_v`

If any requirement is violated, the submission is infeasible.

---

## Objective

Minimize the total cost:

\[
\sum_{(i,j)\text{ used}} \left( b_i + b_j + G \cdot [t_i \ne t_j] \right)
\;+\;
\sum_{(i,j)\text{ used}} k_{ij} \cdot (|x_i-x_j|+|y_i-y_j|)
\]

where `k_{ij}` is the printed usage count of link `(i, j)`.

Lower is better.

---

## Scoring

For each test case:

- if your output is infeasible, your score for that test is `0`
- otherwise let:
  - `C` = your total cost
  - `B` = baseline total cost

Your score for that test is:

\[
10^6 \cdot \min\left(2,\; \frac{B}{C}\right)
\]

So:
- matching the baseline gives `1,000,000`
- doing better than the baseline gives more than `1,000,000`
- scores are capped at `2,000,000` per test

The final score is the average of test scores over all test cases.

### Baseline

The baseline is defined deterministically as follows.

Let:

\[
S = \sum_{i=1}^{n} a_i
\]

Construct a circular sequence of length `S` by writing:
- `a_1` copies of label `1`,
- then `a_2` copies of label `2`,
- ...
- then `a_n` copies of label `n`.

For every position `p` from `0` to `S/2 - 1`, pair the label at position `p` with the label at position `p + S/2` (indices taken in this linear order, not modulo beyond `S-1`).

Because official tests satisfy `max(a_i) <= S/2`, this never pairs a reactor with itself.

Aggregate equal unordered pairs, compute their costs with the same objective formula, and that total is `B`.

---

## Constraints
- Time limit: 3 seconds
- Memory limit: 512 MB

---

## Example

### Input
```text
4 10
1 0 0 3 1
1 1 0 2 1
2 10 0 1 2
2 11 0 1 2
```

### Output
```text
2
1 2 1
3 4 2
```

### Explanation

This solution uses:
- link `(1,2)` once
- link `(3,4)` twice

All reactor charges become zero:
- reactor 1: used once
- reactor 2: used once
- reactor 3: used twice
- reactor 4: used twice

Cost:
- `(1,2)`: calibration `3+2+0=5`, distance `1`, used `1` time → `5 + 1*1 = 6`
- `(3,4)`: calibration `1+1+0=2`, distance `1`, used `2` times → `2 + 2*1 = 4`

Total objective value: `10`.

The baseline for this instance is much more expensive, so this output would score above the baseline.
