# XOR Mask Library Design

## Problem
You are designing a library of broadcast calibration masks for a fleet of devices.

There are `N` devices. Device `i` has:

- an initial non-negative integer value `A_i`
- a positive importance weight `W_i`

You may publish up to `L` distinct calibration masks.  
If a device uses a mask `X`, its value changes from `A_i` to:

- `A_i xor X`, if that is smaller than `A_i`
- otherwise it stays at `A_i`

Equivalently, after publishing a set `S` of masks, device `i` ends with

\[
R_i(S)=\min\left(A_i,\ \min_{X\in S}(A_i \oplus X)\right)
\]

where `xor` is the bitwise XOR operation.

Publishing a mask is not free.  
For each published mask `X`, you pay a setup cost

\[
\alpha + \beta \cdot \mathrm{popcount}(X)
\]

where `popcount(X)` is the number of `1` bits in the binary representation of `X`.

Your task is to choose a feasible set of masks that minimizes the total weighted final value of all devices plus the total setup cost.

This is an optimization challenge: you should output any feasible solution. Better solutions receive higher scores.

---

## Input
The input is given in the following format:

```text
T
case_1
case_2
...
case_T
```

Each test case is:

```text
N L α β
A_1 W_1
A_2 W_2
...
A_N W_N
```

### Meaning
- `T`: number of test cases
- `N`: number of devices
- `L`: maximum number of masks you may publish
- `α, β`: non-negative integers used in the setup-cost formula
- `A_i`: initial value of device `i`
- `W_i`: importance weight of device `i`

---

## Output
For each test case, output exactly one line in the following format:

```text
m X_1 X_2 ... X_m
```

where:

- `m` is the number of published masks
- `0 <= m <= L`
- `X_1, X_2, ..., X_m` are pairwise distinct integers
- each `X_j` must satisfy `0 <= X_j < 2^30`

If `m = 0`, output just:

```text
0
```

### Feasibility requirements
A submission is **feasible** for a test case if all of the following hold:

- the line is well-formed
- `m` is within the allowed range
- all masks are integers in `[0, 2^30)`
- all masks are distinct

If a test case output is infeasible, that test case receives score `0`.

---

## Objective
For a chosen mask set `S = {X_1, ..., X_m}`, define:

\[
R_i(S)=\min\left(A_i,\ \min_{X\in S}(A_i \oplus X)\right)
\]

with the convention that if `S` is empty, then `R_i(S)=A_i`.

The objective value to minimize is:

\[
\mathrm{OBJ}(S)=\sum_{i=1}^{N} W_i \cdot R_i(S)\ +\ \sum_{X\in S}\left(\alpha+\beta\cdot \mathrm{popcount}(X)\right)
\]

The judge computes this value exactly.

---

## Scoring
For each test case, let:

- `O` = your objective value
- `B` = the **baseline** objective value defined below

Your score for that test case is:

\[
\mathrm{Score}_{case}
=
\left\lfloor
2{,}000{,}000 \cdot \frac{B+1}{B+O+2}
\right\rfloor
\]

This value is always in `[0, 2,000,000)` for feasible outputs.

Your total score is the sum of `Score_case` over all test cases.

### Baseline
For each test case, the baseline set of masks is constructed deterministically as follows.

Let the candidate set be the distinct input values:

\[
C = \{A_1, A_2, \dots, A_N\}
\]

Start with `S = ∅`.  
Repeat for at most `L` steps:

1. For every `X in C \ S`, compute `OBJ(S ∪ {X})`.
2. Let `X*` be the candidate giving the smallest objective value.
   - Break ties by choosing the smaller `X`.
3. If `OBJ(S ∪ {X*}) < OBJ(S)`, update `S := S ∪ {X*}`.
   Otherwise stop.

The final `OBJ(S)` is the baseline value `B`.

### Notes
- Matching the baseline gives a score close to `1,000,000` on that test case.
- Better-than-baseline solutions score above that.
- Worse solutions still receive partial credit if feasible.

---

## Constraints
- `1 <= T <= 20`
- `1 <= N <= 5000`
- `1 <= sum of N over all test cases <= 50000`
- `0 <= A_i < 2^30`
- `1 <= W_i <= 10^4`
- `0 <= α <= 10^6`
- `0 <= β <= 10^6`
- `0 <= L <= 30`

All objective calculations fit in signed 64-bit integers.

- Time limit: 10 seconds
- Memory limit: 1024 MB

---

## Example
### Sample Input
```text
2
4 2 3 1
5 1
6 2
1 1
7 1
5 3 2 2
3 1
8 1
7 1
12 2
15 1
```

### Sample Output
```text
2 5 1
1 12
```

### Explanation
In the first test case, the chosen masks are `{5, 1}`.

- Device 1: `min(5, 5 xor 5, 5 xor 1) = min(5, 0, 4) = 0`
- Device 2: `min(6, 3, 7) = 3`
- Device 3: `min(1, 4, 0) = 0`
- Device 4: `min(7, 2, 6) = 2`

Weighted final-value sum:

\[
1\cdot 0 + 2\cdot 3 + 1\cdot 0 + 1\cdot 2 = 8
\]

Setup cost:

- `5` has `popcount = 2`, so cost `3 + 1*2 = 5`
- `1` has `popcount = 1`, so cost `3 + 1*1 = 4`

Total objective:

\[
8 + 5 + 4 = 17
\]

In the second test case, the chosen mask is `{12}`.

This optimization problem has a very large search space: there are up to `2^30` possible masks, but only `L` may be chosen, and their usefulness depends on all devices together. Exact optimization is not expected; heuristic methods are the intended approach.
