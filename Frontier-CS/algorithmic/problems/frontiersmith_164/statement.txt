# Skyline Sculptor

## Problem

A construction robot must sculpt a 1D skyline.

There are `n` plots indexed from `0` to `n-1`.  
Initially, every plot has height `0`.

You may program the robot with at most `M` passes. Each pass is one of:

- `1 L R h` — **Fill pass**  
  For every `i` in `[L, R]`, set `x[i] = max(x[i], h)`.

- `2 L R h` — **Cut pass**  
  For every `i` in `[L, R]`, set `x[i] = min(x[i], h)`.

Here `x[i]` is the current height of plot `i`.

Your goal is to make the final skyline as close as possible to a given target skyline `T[0..n-1]`.  
Each plot also has an importance weight `W[i]`; mistakes on more important plots hurt more.

You are free to choose both the number of passes and all pass parameters, subject to the feasibility rules below.

---

## Input

The input describes one test instance.

- The first line contains two integers `n` and `M`.
- The second line contains `n` integers `T[0], T[1], ..., T[n-1]` — the target heights.
- The third line contains `n` integers `W[0], W[1], ..., W[n-1]` — the importance weights.

### Constraints on the input

- `1 <= n <= 200000`
- `1 <= M <= 2000`
- `0 <= T[i] <= 100000`
- `1 <= W[i] <= 1000`

All objective values fit in signed 64-bit integers.

---

## Output

On the first line, output an integer `q` — the number of passes you want to use.

Then output `q` lines, each in one of the following forms:

- `1 L R h`
- `2 L R h`

### Feasibility requirements

Your output is **feasible** iff all of the following hold:

- `0 <= q <= M`
- For every pass:
  - `t` is either `1` or `2`
  - `0 <= L <= R < n`
  - `0 <= h <= 100000`

The judge will simulate your passes in the given order, starting from the all-zero skyline.

If your output is infeasible, your score for that test is `0`.

---

## Objective

Let `x[i]` be the final height of plot `i` after applying all your passes.

Your objective value is the **weighted absolute error**

\[
E = \sum_{i=0}^{n-1} W[i] \cdot |x[i] - T[i]|.
\]

You must **minimize** `E`.

A smaller `E` is always better.

---

## Scoring

For each test instance, a deterministic **baseline solution** is defined as follows.

### Baseline construction

Let

\[
B = \left\lceil \frac{n}{M} \right\rceil.
\]

Partition the array into consecutive blocks of length `B` (the last block may be shorter):

- block `0`: `[0, B-1]`
- block `1`: `[B, 2B-1]`
- ...

For each block `[L, R]`:

1. Compute the **weighted median** of the target heights `T[L..R]` using weights `W[L..R]`.
2. Let this median be `h`.
3. If `h > 0`, the baseline outputs exactly one fill pass:
   - `1 L R h`

Since the blocks are disjoint and the initial skyline is zero, the baseline final skyline is constant on each block.

### Weighted median definition

For a block `[L, R]`, let

\[
S = \sum_{i=L}^{R} W[i].
\]

Sort the pairs `(T[i], W[i])` by `T[i]` ascending.  
The weighted median is the **smallest** height `h` such that the cumulative weight of all positions with `T[i] <= h` is at least

\[
\left\lceil \frac{S}{2} \right\rceil.
\]

Let `E_base` be the baseline objective value.

### Per-test score

If your solution is infeasible, the score is `0`.

Otherwise, let your objective value be `E`. Your per-test score is

\[
\text{score} = \left\lfloor 10^6 \cdot \min\left(10,\; \frac{E_{base}}{\max(1, E)} \right) \right\rfloor.
\]

Notes:

- The baseline always gets exactly `1,000,000` points on that test.
- Better-than-baseline solutions score above `1,000,000`.
- A perfect solution (`E = 0`) gets the maximum per-test score of `10,000,000`.

### Overall score

Your final contest score is the average of the per-test scores over all official test files, rounded down.

---

## Constraints

- Time limit: 4 seconds
- Memory limit: 512 MB

---

## Example

### Sample input
```text
6 2
4 4 1 1 4 4
1 1 3 3 1 1
```

### Sample output
```text
2
1 0 5 4
2 2 3 1
```

### Explanation

Start from:

`[0, 0, 0, 0, 0, 0]`

After `1 0 5 4`:

`[4, 4, 4, 4, 4, 4]`

After `2 2 3 1`:

`[4, 4, 1, 1, 4, 4]`

This matches the target exactly, so:

\[
E = 0.
\]

The baseline uses `B = ceil(6/2) = 3`, so it splits into blocks `[0,2]` and `[3,5]`.  
Each block gets one fill pass to its weighted median height, producing a nonzero baseline error.  
Since the sample output is perfect, it receives the maximum per-test score.
