# Budgeted Bichromatic Conveyor Reordering

## Problem

A factory conveyor holds `n` items in a line, numbered from `1` to `n`.

Each item `i` has:

- a value `a_i`
- a type `b_i` (`0` or `1`)
- a weight `w_i`

The factory wants the line to be as close as possible to sorted order by value. However, the robot arm is limited:

- In one move, it may choose two positions `x` and `y` and swap the **current** items at those positions.
- A swap is allowed **only if the two swapped items currently have different types**.
- If the swapped items are `u` and `v`, the energy cost of the swap is

\[
|x-y|\cdot (w_u+w_v)
\]

For each test case, you are given:

- a maximum number of swaps `K`
- a total energy budget `B`

Your task is to output any feasible sequence of swaps that minimizes the final disorder of the line.

To make the target ordering unique even when equal values exist, define the **canonical sorted order** as sorting items by:

1. increasing `a_i`
2. breaking ties by original index `i`

Let `target_i` be the position of item `i` in this canonical sorted order.

After all your swaps, if item `i` ends at position `pos_i`, its contribution to disorder is:

\[
w_i \cdot |pos_i - target_i|
\]

The total disorder is:

\[
D = \sum_{i=1}^{n} w_i \cdot |pos_i - target_i|
\]

You must minimize `D`.

---

## Input

The first line contains one integer `t` — the number of test cases.

Each test case consists of:

- one line with three integers `n`, `K`, `B`
- one line with `n` integers `a_1, a_2, \dots, a_n`
- one line with `n` integers `b_1, b_2, \dots, b_n`
- one line with `n` integers `w_1, w_2, \dots, w_n`

### Constraints

- `1 <= t <= 25`
- `2 <= n <= 5000`
- `0 <= K <= 3000`
- `0 <= B <= 10^12`
- `1 <= a_i <= 10^9`
- `b_i ∈ {0,1}`
- `1 <= w_i <= 10^6`
- Sum of `n` over all test cases does not exceed `50000`

---

## Output

For each test case, output:

- one line containing an integer `m` — the number of swaps you perform
- then `m` lines, each containing two integers `x y` (`1 <= x, y <= n`, `x != y`) describing one swap in order

### Feasibility requirements

Your output for a test case is **feasible** iff all of the following hold:

- `0 <= m <= K`
- every printed swap is applied in order to the current arrangement
- for every swap, the two current items at positions `x` and `y` have different types
- the sum of energy costs of all swaps is at most `B`

If any of these conditions is violated, the test case receives score `0`.

---

## Objective

For each test case, minimize the final disorder

\[
D = \sum_{i=1}^{n} w_i \cdot |pos_i - target_i|
\]

where:

- `target_i` is the position of item `i` in the canonical sorted order by `(a_i, i)`
- `pos_i` is the final position of item `i` after applying your swap sequence

Lower `D` is better.

---

## Scoring

For each test case:

- Let `D_init` be the disorder of the initial arrangement (the baseline: perform **no swaps**).
- Let `D_sub` be the disorder of your feasible output.

The per-test score is:

- `0`, if your output is infeasible
- `1`, if `D_init = 0` and `D_sub = 0`
- `0`, if `D_init = 0` and `D_sub > 0`
- otherwise

\[
\text{score}_{test} = \operatorname{clamp}\left(\frac{D_{init} - D_{sub}}{D_{init}},\, 0,\, 1\right)
\]

where `clamp(x,0,1)=max(0,min(1,x))`.

So:

- doing nothing gets score `0` on non-sorted cases
- perfectly reaching the canonical sorted order gets score `1`
- partial improvement gets proportional partial credit

The final score is:

\[
10^6 \cdot \frac{1}{t}\sum \text{score}_{test}
\]

Higher is better.

---

## Constraints
- Time limit: 2 seconds
- Memory limit: 256 MB

---

## Example

### Input
```text
1
5 2 12
5 1 4 2 3
0 1 0 1 0
3 2 1 2 4
```

### Output
```text
2
1 2
3 4
```

### Explanation

Initial items are:

- `1: (a=5, b=0, w=3)`
- `2: (a=1, b=1, w=2)`
- `3: (a=4, b=0, w=1)`
- `4: (a=2, b=1, w=2)`
- `5: (a=3, b=0, w=4)`

The canonical sorted order by `(a_i, i)` is item IDs:

`[2, 4, 5, 3, 1]`

So the target positions are:

- item `2 -> 1`
- item `4 -> 2`
- item `5 -> 3`
- item `3 -> 4`
- item `1 -> 5`

The swaps are valid because each swap exchanges opposite types.

Energy used:

- swap `(1,2)`: distance `1`, cost `1*(3+2)=5`
- swap `(3,4)`: distance `1`, cost `1*(1+2)=3`

Total energy = `8 <= 12`, and `2 <= K`.

The initial disorder is `27`.
The final disorder after these swaps is `19`.

So the per-test score is:

\[
\frac{27-19}{27} = \frac{8}{27} \approx 0.2963
\]

This is only an example; a better swap plan may exist.
