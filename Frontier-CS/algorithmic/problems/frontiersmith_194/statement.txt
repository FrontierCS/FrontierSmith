# Noodle Stall Deployment

## Problem
Wu wants to run a one-day instant-noodle festival.

There are `L` candidate cooking stalls and `R` customer groups.  
Customer group `i` brings revenue `c_i` if it is served.

A stall `u`:

- costs `a_u` to rent,
- can serve at most `b_u` customer groups,
- can serve customer group `i` only if there is an edge `(u, i)` in the given bipartite graph.

Each customer group may be served by **at most one** rented stall.  
The total rental cost of all rented stalls must not exceed the budget `B`.

Your task is to choose which stalls to rent and how to assign customer groups to rented stalls so as to maximize total revenue.

This is an **optimization problem**: any feasible solution is accepted, and better solutions receive higher scores.

## Input
The first line contains a single integer `T` — the number of test cases.

Each test case has the following format:

- One line with four integers `L`, `R`, `M`, `B`  
  (`L` stalls, `R` customer groups, `M` edges, budget `B`)
- One line with `L` integers `a_1, a_2, ..., a_L` — rental costs
- One line with `L` integers `b_1, b_2, ..., b_L` — capacities
- One line with `R` integers `c_1, c_2, ..., c_R` — revenues
- `M` following lines each contain two integers `u`, `v`, meaning stall `u` can serve customer group `v`

There are no multiple edges.

## Output
For each test case, output exactly one line with `R` integers:

- `x_i = 0` means customer group `i` is left unserved
- `x_i = u` (`1 <= u <= L`) means customer group `i` is assigned to stall `u`

A test case output is **feasible** iff all of the following hold:

1. For every `i` with `x_i = u > 0`, edge `(u, i)` exists.
2. For every stall `u`, the number of groups assigned to `u` is at most `b_u`.
3. Let `S = { u | x_i = u for at least one i }` be the set of used stalls. Then  
   `sum_{u in S} a_u <= B`.

If your output for a test case is malformed or infeasible, its objective value for that test case is `0`.

## Objective
For a feasible solution, the objective value is

\[
\text{Revenue} = \sum_{i : x_i \neq 0} c_i
\]

That is, the sum of revenues of all served customer groups.

Your goal is to **maximize** this value.

## Scoring
For each test case `t`:

- Let `O_t` be your objective value.
- Let `U_t = sum_{i=1..R} c_i` be the total revenue of all customer groups.
- Let `G_t` be the objective value of the following **baseline solution**.

### Baseline solution
Initially:

- all customer groups are unassigned,
- all stalls are closed,
- remaining budget is `B`.

Repeat:

1. For each still-closed stall `u` with `a_u <= remaining_budget`, define `Cand(u)` as follows:
   - consider currently unassigned neighbors of `u`,
   - sort them by decreasing `c_i`, breaking ties by smaller `i`,
   - take the first `b_u` of them (or all of them if fewer exist).
2. Let  
   \[
   gain(u) = \sum_{i \in Cand(u)} c_i
   \]
3. If every feasible closed stall has `gain(u) = 0`, stop.
4. Choose the stall maximizing `gain(u) / a_u`.
   - Compare ratios exactly by cross multiplication.
   - Break ties by larger `gain(u)`.
   - If still tied, choose smaller `u`.
5. Open that stall, decrease remaining budget by its cost, and permanently assign all groups in `Cand(u)` to it.

The resulting total assigned revenue is `G_t`.

### Per-test score
If `G_t = U_t`, then

- score is `1` if `O_t = U_t`,
- score is `0` otherwise.

Else,

\[
s_t = \mathrm{clamp}\left(\frac{O_t - G_t}{U_t - G_t},\, 0,\, 1\right)
\]

where `clamp(x,0,1) = max(0, min(1, x))`.

### Final score
If there are `T` test cases, your final score is

\[
\left\lfloor 10^6 \cdot \frac{1}{T} \sum_{t=1}^{T} s_t \right\rfloor
\]

So:

- matching the baseline on a test gives score contribution `0`,
- reaching full possible revenue gives score contribution `1`,
- partial improvements over the baseline are rewarded proportionally.

## Constraints
- `1 <= T <= 2000`
- `1 <= L, R <= 500000`
- `0 <= M <= 500000`
- `0 <= B <= 10^{12}`
- `1 <= a_u <= 10^9`
- `1 <= b_u <= R`
- `1 <= c_i <= 10^{12}`
- Total `L` over all test cases does not exceed `500000`
- Total `R` over all test cases does not exceed `500000`
- Total `M` over all test cases does not exceed `500000`

- Time limit: 3 seconds
- Memory limit: 512 MB

## Example
### Sample input
```text
1
3 4 7 5
3 2 2
2 2 1
10 8 7 6
1 1
1 2
1 4
2 2
2 3
3 3
3 4
```

### Sample output
```text
1 2 2 1
```

### Explanation
- Customer group `1` is assigned to stall `1`
- Customer groups `2` and `3` are assigned to stall `2`
- Customer group `4` is assigned to stall `1`

Used stalls are `{1, 2}` with total cost `3 + 2 = 5`, which fits the budget.

Capacities:
- stall `1` serves 2 groups, capacity `2`
- stall `2` serves 2 groups, capacity `2`

All assignments follow existing edges, so the solution is feasible.

Objective value:
\[
10 + 8 + 7 + 6 = 31
\]

Since all customer groups are served, this also equals the upper bound `U_1 = 31`, so this test case receives full score.
