# Extreme Observers

## Problem
A museum will unveil the artifacts labeled `1, 2, ..., n` one by one, in some order.

There are `q` independent observers. Observer `j` only pays attention to a specified set `S_j` of artifacts. Consider the subsequence of your unveiling order that contains only the artifacts from `S_j`, in the order they appear globally.

For each observer, the first watched artifact produces no symbol. For every later watched artifact:

- write `>` if it is larger than every watched artifact previously seen by this observer;
- write `<` if it is smaller than every watched artifact previously seen by this observer;
- write `?` otherwise.

So observer `j` produces a string of length `|S_j|-1`.

For every observer, a target string `t_j` and a weight `w_j` are given. Your task is to output one permutation of `1..n` that maximizes the total weighted number of matching characters across all observers.

This is an optimization problem: any feasible permutation is accepted, and better permutations receive higher scores.

## Input
The first line contains two integers `n` and `q`.

Then `q` observer descriptions follow.

For each observer `j`:

- the first line contains two integers `k_j` and `w_j` — the number of watched artifacts and the observer's weight;
- the second line contains `k_j` distinct integers `a_{j,1}, a_{j,2}, ..., a_{j,k_j}` — the watched set `S_j`;
- the third line contains a string `t_j` of length `k_j - 1`, consisting only of the characters `<`, `>` and `?`.

The order of the integers on the second line is irrelevant: it defines a set, not a preferred order.

## Output
Output one line with `n` integers — a permutation `p_1, p_2, ..., p_n` of `1..n`.

A submission is **feasible** iff every integer from `1` to `n` appears exactly once.

If the output is not a feasible permutation, its objective value is `0`.

## Objective
For a feasible permutation `p`, define the score of observer `j` as follows.

Let `x_1, x_2, ..., x_{k_j}` be the elements of `S_j` sorted by their positions in `p` (earlier in `p` means earlier in this sequence).

Construct the produced string `r_j` of length `k_j-1`:

- initialize `mn = mx = x_1`;
- for `i = 2..k_j`:
  - if `x_i < mn`, append `<` and set `mn = x_i`;
  - else if `x_i > mx`, append `>` and set `mx = x_i`;
  - else append `?`.

Let `match_j` be the number of positions `c` such that `r_j[c] = t_j[c]`.

The total objective value is

\[
\mathrm{Obj}(p) = \sum_{j=1}^{q} w_j \cdot match_j.
\]

You must **maximize** `Obj(p)`.

## Scoring
For each test instance:

- `U = \sum_{j=1}^{q} w_j \cdot (k_j-1)` is the trivial upper bound;
- `B = Obj(1,2,\dots,n)` is the baseline value obtained by the identity permutation.

Let your objective value be `X`.

The normalized score for that instance is:

- `0`, if your output is infeasible;
- `1`, if `U = B`;
- otherwise

\[
\mathrm{norm} = \operatorname{clamp}\left(\frac{X - B}{U - B}, 0, 1\right),
\]

where `clamp(v,0,1)=max(0,min(1,v))`.

The contest score is

\[
10^6 \times \text{average of }\mathrm{norm}\text{ over all test instances}.
\]

Thus:
- matching the baseline gets score `0` on that instance,
- reaching the upper bound gets score `1`,
- partial improvements receive proportional partial credit.

## Constraints
- `2 <= n <= 2 * 10^5`
- `1 <= q <= 2 * 10^5`
- `2 <= k_j <= 50`
- `1 <= w_j <= 10^6`
- all numbers inside one watched set are distinct
- `1 <= a_{j,i} <= n`
- `sum of all k_j over all observers <= 4 * 10^5`

## Constraints
- Time limit: 2 seconds
- Memory limit: 256 MB

## Example
Input
```text
5 3
3 4
1 3 5
><
4 2
2 3 4 5
><?
2 5
1 2
<
```

Output
```text
3 5 2 1 4
```

Brief explanation:

- Observer 1 watches `{1,3,5}` and sees `3,5,1`, producing `><`, which matches both target characters: gain `4 * 2 = 8`.
- Observer 2 watches `{2,3,4,5}` and sees `3,5,2,4`, producing `><?`, matching all three: gain `2 * 3 = 6`.
- Observer 3 watches `{1,2}` and sees `2,1`, producing `<`, matching once: gain `5 * 1 = 5`.

Total objective: `8 + 6 + 5 = 19`.

For the baseline permutation `1 2 3 4 5`, the objective is `6`, and the upper bound is also `19`, so this sample output achieves the maximum possible normalized score on this instance.
