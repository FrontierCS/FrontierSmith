# Rectangular Gallery Zoning

## Problem
A museum floor is represented by an `n × m` grid.  
Cell `(i, j)` contains an artifact with integer label `a[i][j]`.

You may divide the floor into a collection of **axis-aligned rectangular galleries**.  
Each gallery must satisfy the following rule:

- **Clean gallery**: all labels inside the rectangle are pairwise distinct.

Your galleries must also satisfy:

- every gallery is non-empty,
- galleries are **cell-disjoint** (no cell may belong to two galleries),
- galleries may touch by sides or corners.

You may leave some cells uncovered, although this is usually not beneficial.

For a gallery with area `s`, its utility is `s²`.  
Your goal is to choose galleries maximizing the total utility.

This is an optimization problem: better solutions receive higher scores.

## Input
The input contains one instance.

- The first line contains two integers `n` and `m` (`1 ≤ n, m ≤ 400`).
- Each of the next `n` lines contains `m` integers:
  `a[i][j]` (`1 ≤ a[i][j] ≤ 10^9`).

## Output
Print a zoning plan:

- The first line contains one integer `k` — the number of galleries (`0 ≤ k ≤ n·m`).
- Each of the next `k` lines contains four integers  
  `i1 j1 i2 j2` describing one rectangle:
  `1 ≤ i1 ≤ i2 ≤ n`, `1 ≤ j1 ≤ j2 ≤ m`.

A rectangle represents all cells `(i, j)` such that `i1 ≤ i ≤ i2` and `j1 ≤ j ≤ j2`.

### Feasibility requirements
Your output is **feasible** if all of the following hold:

1. all `k` rectangles are within bounds,
2. no two rectangles share a cell,
3. every rectangle is a clean gallery, i.e. all labels inside it are distinct.

If any requirement is violated, the solution is treated as infeasible and its objective value is `0`.

## Objective
For a feasible solution, let the chosen galleries have areas `s1, s2, ..., sk`.

The objective value is

\[
A = \sum_{t=1}^{k} s_t^2
\]

You must **maximize** `A`.

Notes:

- A single cell is always a valid gallery of area `1`.
- Since galleries are disjoint, the total covered area is at most `n·m`.
- Therefore `A ≤ (n·m)^2`.

## Scoring
Let:

- `A` = your objective value,
- `B = n·m` = the objective of the baseline solution that uses every cell as its own `1 × 1` gallery,
- `U = (n·m)^2` = a valid upper bound on the objective.

### Per-instance score
If `n·m = 1`:

- score is `100` if `A = 1`,
- score is `0` otherwise.

Otherwise, the per-instance score is

\[
\text{score} = 100 \cdot \mathrm{clamp}\!\left(
\frac{\ln(A+1)-\ln(B+1)}{\ln(U+1)-\ln(B+1)},
0, 1
\right)
\]

where

\[
\mathrm{clamp}(x,0,1)=\max(0,\min(1,x)).
\]

Thus:

- the baseline solution scores `0`,
- better solutions score higher,
- reaching the upper bound `U` scores `100`.

### Overall score
If the test set contains multiple hidden instances, the final score of a submission is the arithmetic mean of its per-instance scores.

## Constraints
- Time limit: 3 seconds
- Memory limit: 512 MB

## Example
### Sample input
```text
3 4
1 2 3 4
5 1 6 7
8 9 10 11
```

### Sample output
```text
3
1 2 3 4
2 1 3 1
1 1 1 1
```

### Explanation
The three galleries are:

1. rows `1..3`, cols `2..4`  
   labels = `{2,3,4,1,6,7,9,10,11}` — all distinct, area `9`
2. rows `2..3`, col `1`  
   labels = `{5,8}` — distinct, area `2`
3. row `1`, col `1`  
   label = `{1}`, area `1`

They are disjoint, so the solution is feasible.

Objective value:

\[
A = 9^2 + 2^2 + 1^2 = 81 + 4 + 1 = 86
\]

Baseline value:

\[
B = n \cdot m = 12
\]

Upper bound:

\[
U = 12^2 = 144
\]

So this solution scores strictly above the baseline.
