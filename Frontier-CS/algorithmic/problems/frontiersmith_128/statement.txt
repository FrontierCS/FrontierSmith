# Never-Continued Tales

## Problem

Lingluo no longer wants to **compute** a fairy tale continuation — she wants to **design** one.

There are chapters numbered from `0` to `n`.  
If chapter `i` is given an initial inspiration value `x_i`, then inspiration spreads forward by the following routine:

```cpp
g[i] = x_i   for all 0 <= i <= n
for (int t = 1; t <= n; t++) {
    for (int i = 1; i <= n; i++) {
        g[i] = sat(g[i] + a * g[i - 1]);
    }
    ans[t] = g[t];
}
```

Here `sat(v) = min(v, CAP)` and `CAP = 10^18`.

So the output sequence `ans[1], ans[2], ..., ans[n]` is determined entirely by your chosen initial values `x_0, x_1, ..., x_n`.

Lingluo has a desired continuation profile `b_1, b_2, ..., b_n`.  
Your task is to choose the initial inspirations `x_i` under a budget, so that the produced sequence `ans` is as close as possible to `b`.

Each chapter `i` has:

- a **fixed activation cost** `p_i` if `x_i > 0`,
- a **per-unit cost** `q_i` for each unit of inspiration,
- a **maximum allowed inspiration** `u_i`.

If you choose `x_i`, then:

- `x_i` must be an integer,
- `0 <= x_i <= u_i`,
- the total cost must satisfy

\[
\sum_{i : x_i > 0} p_i + \sum_{i=0}^{n} q_i x_i \le B
\]

The quality of your continuation is measured by the weighted absolute error:

\[
E = \sum_{t=1}^{n} w_t \cdot |ans_t - b_t|
\]

Smaller `E` is better.

---

## Input

A single test case.

The first line contains three integers:

- `n` — number of continuation milestones,
- `a` — spread parameter,
- `B` — total budget.

The second line contains `n+1` integers:

- `p_0, p_1, ..., p_n`

The third line contains `n+1` integers:

- `q_0, q_1, ..., q_n`

The fourth line contains `n+1` integers:

- `u_0, u_1, ..., u_n`

The fifth line contains `n` integers:

- `b_1, b_2, ..., b_n`

The sixth line contains `n` integers:

- `w_1, w_2, ..., w_n`

---

## Output

Output any feasible continuation plan in the following format:

- The first line contains an integer `s` — the number of indices with positive inspiration.
- Each of the next `s` lines contains two integers `i x`:
  - `i` is an index in `[0, n]`,
  - `x` is the chosen inspiration value for chapter `i`.

Requirements:

- All listed indices must be distinct.
- For listed pairs, `1 <= x <= u_i`.
- For omitted indices, the judge assumes `x_i = 0`.
- The total cost must not exceed `B`.

If your output is infeasible, the score for that test is `0`.

---

## Objective

Minimize

\[
E = \sum_{t=1}^{n} w_t \cdot |ans_t - b_t|
\]

where `ans` is generated from your chosen `x_0, x_1, ..., x_n` by:

```cpp
g[i] = x_i
for (t = 1..n) {
    for (i = 1..n) {
        g[i] = sat(g[i] + a * g[i - 1]);
    }
    ans[t] = g[t];
}
```

and

\[
sat(v) = \min(v, 10^{18})
\]

All calculations are done over integers.

---

## Scoring

For each test case, define the **baseline solution** as:

- choose `x_i = 0` for all `i`.

This is always feasible, and it produces `ans_t = 0` for all `t`, so its error is

\[
E_{\text{base}} = \sum_{t=1}^{n} w_t \cdot b_t
\]

Since all `b_t >= 1` and `w_t >= 1`, we have `E_base > 0`.

Your score on a test case is:

\[
\text{score} =
10^6 \cdot \max\left(0,\ 1 - \frac{E}{E_{\text{base}}}\right)
\]

That is:

- matching the baseline gets score `0`,
- improving on the baseline gives a positive score,
- a perfect match (`E = 0`) gets score `10^6`.

The final score is the arithmetic mean of the scores over all official test cases.

---

## Constraints

- `2 <= n <= 3500`
- `1 <= a <= 10^9`
- `0 <= B <= 10^12`
- `0 <= p_i <= 10^9`
- `0 <= q_i <= 10^9`
- `0 <= u_i <= 10^9`
- `1 <= b_t <= 10^18`
- `1 <= w_t <= 10^6`

All input values are integers.

- Time limit: 4 seconds
- Memory limit: 512 MB

---

## Example

### Input
```text
3 1 5
0 1 1 1
1 1 1 1
5 5 5 5
2 5 9
1 1 1
```

### Output
```text
1
0 1
```

### Explanation

This chooses:

- `x_0 = 1`
- all other `x_i = 0`

The cost is:

\[
0 + 1 \cdot 1 = 1 \le 5
\]

Simulation:

- Initial: `g = [1, 0, 0, 0]`
- After `t = 1`: `g = [1, 1, 1, 1]`, so `ans_1 = 1`
- After `t = 2`: `g = [1, 2, 3, 4]`, so `ans_2 = 3`
- After `t = 3`: `g = [1, 3, 6, 10]`, so `ans_3 = 10`

So the produced sequence is:

\[
ans = [1, 3, 10]
\]

The objective value is:

\[
E = |1-2| + |3-5| + |10-9| = 4
\]

The baseline error is:

\[
E_{\text{base}} = 2 + 5 + 9 = 16
\]

Therefore the score is:

\[
10^6 \cdot \left(1 - \frac{4}{16}\right) = 750000
\]
