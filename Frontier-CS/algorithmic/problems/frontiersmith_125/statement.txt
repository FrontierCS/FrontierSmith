# XOR Patch Routing

## Problem
A communication network is represented by a connected undirected graph.  
Each link has:

- a **length** (the cost to send a signal through it once),
- a **penalty weight** (how harmful a remaining fault on that link is),
- a 4-bit **fault mask** `a` in `[0, 15]`.

You may perform any number of **patch operations**.

In one patch operation, you choose:

- a **simple path** in the graph,
- an integer `x` with `1 ≤ x ≤ 15`.

Then every edge on that path changes its fault mask by:

`a_e ← a_e XOR x`

Each patch operation has a cost:

`setup_fee + (sum of lengths of all edges on the chosen path)`

After all operations, every edge whose final mask is nonzero contributes a remaining-fault penalty:

`penalty_weight_e × final_mask_e`

Your task is to output any feasible sequence of patch operations that minimizes:

`total_patch_cost + total_remaining_fault_penalty`

Because the instance sizes are large, exact optimization is not expected.

---

## Input
Input is given from Standard Input in the following format:

```text
N M S
u_1 v_1 L_1 P_1 a_1
u_2 v_2 L_2 P_2 a_2
:
u_M v_M L_M P_M a_M
```

- `N`: number of vertices
- `M`: number of edges
- `S`: setup fee of one patch operation

For each edge `i`:

- `u_i`, `v_i`: endpoints of the edge
- `L_i`: length of the edge
- `P_i`: penalty weight of the edge
- `a_i`: initial fault mask

Vertices are numbered `0` to `N-1`.

The graph is simple: no self-loops and no multiple edges.

---

## Output
First output an integer `K`, the number of patch operations.

Then output `K` lines.  
For the `j`-th operation, output:

```text
r_j x_j w_{j,0} w_{j,1} ... w_{j,r_j-1}
```

where:

- `r_j` is the number of vertices on the path
- `x_j` is the XOR value for this operation
- `w_{j,0}, ..., w_{j,r_j-1}` is the vertex sequence of the path

### Feasibility requirements
Your output is feasible iff all of the following hold:

- `0 ≤ K ≤ 200000`
- `2 ≤ r_j ≤ N`
- `1 ≤ x_j ≤ 15`
- For every operation, all vertices in the sequence are distinct
- For every consecutive pair  
  `(w_{j,t}, w_{j,t+1})`, there is an edge in the input graph
- The total number of printed vertices over all operations is at most `1000000`

If the output is infeasible, the score for that test is `0`.

When evaluating, each operation is applied in the output order.

---

## Objective
Let:

- `C_ops` = sum of costs of all patch operations
- `C_rem` = sum over all edges of  
  `P_i × final_mask_i`

Your objective value is:

```text
OBJ = C_ops + C_rem
```

Lower is better.

---

## Scoring
For each test case, define the **baseline solution** as follows:

- For every edge with `a_i ≠ 0`, perform exactly one operation on the single-edge path `(u_i, v_i)` with `x = a_i`.

This makes every edge zero, so the baseline objective is:

```text
BASE = Σ over all i with a_i ≠ 0 of (S + L_i)
```

### Per-test score
If your output is infeasible, the per-test score is `0`.

Otherwise, let your objective be `OBJ`.

- If `BASE > 0`:

```text
score = floor(10^6 × min(5, BASE / OBJ))
```

- If `BASE = 0`:
  - `score = 10^6` if `OBJ = 0`
  - `score = 0` otherwise

So:

- matching the baseline gives about `1,000,000` points,
- doing better than the baseline gives more,
- doing worse gives less,
- the ratio is capped at `5`.

### Total score
The total score is the sum of per-test scores over all test cases.

---

## Constraints
- `2 ≤ N ≤ 30000`
- `N-1 ≤ M ≤ 80000`
- `1 ≤ S ≤ 10^6`
- `0 ≤ u_i, v_i < N`
- `1 ≤ L_i ≤ 10^4`
- `1 ≤ P_i ≤ 10^4`
- `0 ≤ a_i ≤ 15`
- The input graph is connected and simple

- Time limit: 3 seconds
- Memory limit: 1024 MB

---

## Example
### Sample Input
```text
4 4 5
0 1 2 7 3
1 2 2 6 3
2 3 1 4 1
0 3 3 5 0
```

### Sample Output
```text
1
3 3 0 1 2
```

### Explanation
The single operation uses the path `0-1-2` and `x = 3`.

- Edge `(0,1)`: `3 XOR 3 = 0`
- Edge `(1,2)`: `3 XOR 3 = 0`
- Edge `(2,3)`: unchanged, remains `1`
- Edge `(0,3)`: unchanged, remains `0`

Patch cost:

- setup fee = `5`
- path length = `2 + 2 = 4`

So `C_ops = 9`.

Remaining penalty:

- only edge `(2,3)` is nonzero
- penalty = `4 × 1 = 4`

Thus:

`OBJ = 9 + 4 = 13`

Baseline:

- repair `(0,1)` alone: `5 + 2 = 7`
- repair `(1,2)` alone: `5 + 2 = 7`
- repair `(2,3)` alone: `5 + 1 = 6`

So `BASE = 20`.

Per-test score:

`floor(10^6 × 20 / 13) = 1538461`
